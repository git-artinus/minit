회의를 녹음하는 앱이니 무엇이 어디로 가는지 분명히 밝힙니다.

## 오디오

**녹음된 오디오는 기기 안에서만 처리됩니다.** 음성 인식은 내려받은 모델로 기기에서 직접
수행하며, 오디오 파일이 외부 서버로 전송되지 않습니다.

원본 오디오는 회의록 저장이 끝난 뒤에도 **로컬에 최대 7일 보존**된 뒤 자동 삭제됩니다.
인식 오류가 의심되는 회의를 다시 확인하거나 복구하기 위한 것입니다.

Minit은 **마이크 입력만** 녹음합니다. 컴퓨터에서 재생되는 소리(화상회의 상대방 음성 등)는
녹음되지 않습니다.

## 회의록

회의록은 **항상 먼저 로컬에 저장**됩니다. 기본 위치는 `~/.minit`이며 설정에서 바꿀 수 있습니다.

## 요약 — 여기서만 텍스트가 나갑니다

요약과 액션아이템 생성에는 Claude Code CLI를 사용합니다. **이 단계에서 회의 내용 텍스트가
Claude로 전송됩니다.**

요약 기능을 쓰지 않으려면 Claude Code CLI를 설치하지 않으면 됩니다. 이 경우 회의 내용까지만
저장되고 요약은 비어 있습니다.

## GitHub 백업 (선택)

연결하면 선택한 저장소의 `minit/` 폴더로 **회의록 파일**이 업로드됩니다. 오디오는 올라가지
않습니다. **로그인하지 않아도 모든 기능을 그대로 쓸 수 있습니다.**

→ [GitHub 백업](../github-backup/)

## Slack 발송 (선택)

설정하면 **회의 요약**이 지정한 채널로 발송됩니다. **기본값은 발송 안 함**입니다.

Minit이 요구하는 Slack 권한은 `chat:write`·`channels:read`·`groups:read` 세 개이며,
이 권한으로는 **채널의 기존 대화 내용을 읽을 수 없습니다.** 봇은 어떤 채널에도 자동으로
참여하지 않습니다.

→ [Slack 자동 발송](../slack/)

## 토큰

GitHub·Slack 토큰은 입력 즉시 **OS 키체인 기반으로 암호화해 저장**하며 평문으로는 어디에도
남기지 않습니다.

## 정리

| 데이터 | 기기 밖으로 나가나요 |
| --- | --- |
| 녹음된 오디오 | **아니요** (7일 뒤 로컬에서 자동 삭제) |
| 회의 내용·요약 | 요약 생성 시 Claude로 전송 |
| 회의록 파일 | GitHub 백업을 켠 경우에만 |
| 회의 요약 | Slack 발송을 켠 경우에만 |
| 토큰 | 아니요 (OS 키체인에 암호화 저장) |
