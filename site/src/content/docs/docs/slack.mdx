회의가 끝나면 요약을 Slack 채널로 자동 발송할 수 있습니다. **기본값은 발송 안 함**입니다.

워크스페이스당 앱·봇 토큰은 **1개면 충분**하고, 발송 채널 선택은 팀원별로 각자 합니다.
아래 두 탭 중 본인에게 해당하는 쪽을 보세요.

<Tabs>
  <TabItem label="워크스페이스 관리자 (최초 1회)">

    이 작업은 워크스페이스에서 **한 번만** 하면 됩니다.

    1. [api.slack.com/apps](https://api.slack.com/apps) → **Create New App** → **From scratch** →
       앱 이름(예: Minit)과 워크스페이스를 선택합니다.
       승인제 워크스페이스라면 설치 시 관리자 승인이 필요할 수 있습니다.

    2. **OAuth & Permissions** → **Scopes** → **Bot Token Scopes** 에 아래 3개를 추가합니다.

       | Scope | 용도 |
       | --- | --- |
       | `chat:write` | 지정한 채널에 회의 요약 메시지를 발송합니다 |
       | `channels:read` | 봇이 참여한 공개 채널 목록을 조회해 설정 화면 드롭다운에 표시합니다 |
       | `groups:read` | 봇이 참여한 비공개 채널 목록을 조회합니다 |

       :::note[이 권한으로 할 수 없는 것]
       이 3개 스코프로는 **채널의 기존 대화 내용을 읽을 수 없습니다.** 봇이 참여한 채널
       목록 조회와 메시지 발송만 가능합니다. 봇은 어떤 채널에도 자동으로 참여하지 않으며,
       팀원이 채널에서 직접 초대해야만 그 채널이 목록에 나타납니다.
       :::

    3. **Install to Workspace**(이미 설치했다면 **Reinstall to Workspace**) → 승인

    4. **OAuth & Permissions** 상단의 **Bot User OAuth Token**(`xoxb-`로 시작)을 복사해
       팀원에게 공유합니다.

    :::caution[토큰은 시크릿입니다]
    공개 채널이 아닌 **비밀 채널이나 패스워드 매니저로** 공유하세요. Minit은 이 토큰을 받는
    즉시 OS 키체인 기반으로 암호화해 저장하며, 평문으로는 어디에도 남기지 않습니다.
    :::

  </TabItem>
  <TabItem label="팀원">

    관리자에게 봇 토큰(`xoxb-...`)을 받은 뒤 진행합니다.

    1. Minit 설정(톱니 아이콘) → **연동 (Slack)** 섹션에서 **봇 토큰 입력**을 누르고
       받은 토큰을 붙여넣어 저장합니다.

    2. 회의 요약을 받을 채널에서 **채널명 → 통합 → 앱 → Minit 추가**로 봇을 초대합니다.
       **초대한 채널만** 설정 화면 드롭다운에 나타납니다.

    3. 설정 화면으로 돌아와 드롭다운(필요하면 **새로고침**)에서 채널을 선택합니다.
       비공개 채널은 🔒로 표시됩니다.

    4. 이후 본인이 종료한 회의의 요약이 선택한 채널로 자동 발송됩니다.

    다른 채널로 바꾸려면 **그 채널에도 먼저 봇을 초대한 뒤** 드롭다운에서 다시 선택합니다.

  </TabItem>
</Tabs>

## 회의별로 다른 채널에 보내기

회의를 시작할 때 그 회의만 다른 채널로 보내거나 발송하지 않도록 지정할 수 있습니다.

## 발송이 실패해도 회의록은 남습니다

채널에 봇을 초대하지 않았거나 네트워크 문제로 발송이 실패해도 **회의록 저장 자체에는 영향이
없습니다.** 앱이 발송 실패를 알려줍니다.

수동으로 보내려면 회의록 오른쪽 위 **공유** → **Slack 채널로 전송**을 쓰세요.
