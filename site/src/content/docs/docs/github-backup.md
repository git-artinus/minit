:::note[선택 사항입니다]
**로그인 없이도 모든 기능을 그대로 쓸 수 있습니다.** 회의록은 항상 먼저 로컬(설정한 저장
위치)에 저장되며, GitHub 연결은 그 위에 얹는 선택적 백업입니다.
:::

## 연결하기

1. 첫 실행 시 뜨는 로그인 팝업에서 **GitHub 연결**을 누릅니다.
   건너뛰었다면 설정(톱니 아이콘) → **GitHub 계정** 섹션에서 **연결**을 누릅니다.
2. 화면에 표시된 **코드를 복사**하고, 브라우저에서 열리는 GitHub 인증 페이지에 입력해 승인합니다.
3. 로그인 후 저장소 목록에서 **회의록을 백업할 저장소를 선택**합니다.

저장소를 처음 선택하면 **자동 동기화** 스위치가 자동으로 켜집니다. 설정 → **GitHub 계정**에서
언제든 끄고 켤 수 있습니다.

## 연결하면 일어나는 일

- 회의록이 저장될 때마다 선택한 저장소의 **`minit/` 폴더로 자동 업로드**됩니다
- **다른 팀원이 올린 회의록도 자동으로 내려받아** 목록에 함께 보여줍니다
- 회의록을 지우면 원격 사본도 함께 삭제됩니다

## 업로드가 실패해도 회의록은 남습니다

인터넷이 끊겨 있거나 업로드가 실패해도 **회의록은 로컬에 그대로** 있습니다.
다음 회의를 저장할 때나 앱에 다시 포커스할 때 자동으로 재시도합니다.

## 저장소 바꾸기 · 로그아웃

설정 → **GitHub 계정** 섹션에서 언제든 저장소를 바꾸거나 로그아웃할 수 있습니다.
로그아웃해도 이미 로컬에 있는 회의록은 지워지지 않습니다.

## 무엇이 전송되나요

선택한 저장소로 **회의록 파일**이 올라갑니다. 녹음된 오디오는 올라가지 않습니다.
자세한 내용은 [데이터 처리](../privacy/)를 참고하세요.
