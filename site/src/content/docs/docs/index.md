## 처음이라면

1. [설치](./install/) — 다운로드부터 실행까지
2. [첫 실행](./first-run/) — 실행 직후 준비되는 것들
3. [회의록 만들기](./recording/) — 녹음부터 공유까지의 전체 흐름
