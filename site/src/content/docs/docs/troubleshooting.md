## "회의 시작" 버튼이 눌리지 않습니다

음성 인식 모델(약 1.6GB)을 처음 한 번 내려받는 중입니다. 우측 하단 설치 패널에서 진행
상황을 볼 수 있습니다. 다운로드가 끝나면 자동으로 활성화되며, 그 전에도 나머지 화면은
그대로 쓸 수 있습니다.

## 요약과 액션아이템이 나오지 않습니다

요약 생성에는 **Claude Code CLI**가 필요합니다. 설치되어 있지 않으면 회의 내용까지만
저장되고 요약은 비어 있습니다.

회의록 화면에서 **요약 재생성**을 누르면 실패한 이유를 함께 알려줍니다.

| 안내 문구 | 해야 할 일 |
| --- | --- |
| Claude CLI가 설치되어 있지 않습니다 | 설정 → **Claude**에서 설치 명령을 복사해 터미널에서 실행한 뒤 **다시 확인**을 누릅니다 |
| Claude에 로그인되어 있지 않습니다 | 터미널에서 `claude` 를 실행해 로그인한 뒤 다시 시도합니다 |
| 사용량 한도에 도달했습니다 | 한도가 초기화된 뒤 다시 시도합니다 |
| 제한 시간을 초과했습니다 | 회의가 길면 시간이 더 걸릴 수 있습니다. 다시 시도합니다 |
| 예상한 형식으로 응답하지 않았습니다 | 다시 시도하면 대개 해결됩니다 |

위에 없는 원인이어도 Claude가 실제로 남긴 메시지가 함께 표시되므로 무엇이 문제인지
확인할 수 있습니다.

설정 → **Claude**에서는 CLI 설치 여부를 언제든 확인할 수 있습니다. 다만 설치되어 있어도
**로그인이 안 되어 있거나 사용량이 남아 있지 않으면** 요약은 만들어지지 않습니다.

## 요약은 나왔는데 저장 경고가 함께 뜹니다

`요약은 저장했지만 git 커밋에 실패했습니다`라고 표시되는 경우입니다. 요약은 정상적으로
만들어져 **회의록 파일에 저장됐고**, 저장 위치의 git 기록만 실패했습니다.

저장 위치를 git 저장소로 지정했는데 git 사용자 정보가 설정되지 않은 경우가 대부분입니다.
터미널에서 해당 저장소에 `git config user.email`·`git config user.name`을 설정하면 다음
저장부터 정상 기록됩니다.

## 새 버전 알림이 뜨지 않습니다

앱은 실행 직후, 이후 **4시간마다**, 그리고 **창을 다시 열 때** 새 버전을 확인합니다.
알림에서 **나중에**를 눌렀더라도 그 뒤에 새 버전이 나오면 다시 알려줍니다.

설정 하단 **버전** 항목의 **업데이트 확인**으로 직접 확인할 수도 있습니다. 자동 확인이
계속 실패하는 경우에는 그 사실과 릴리즈 페이지 링크를 함께 보여줍니다.

## 마이크 권한을 실수로 거부했습니다

`  > 시스템 설정 > 개인정보 보호 및 보안 > 마이크`에서 Minit을 켜고 앱을 다시 실행합니다.

## Intel Mac에서 실행되지 않습니다

Minit은 **Apple Silicon(M1 이상) 전용**입니다. Intel Mac은 지원하지 않습니다.

## 화상회의 상대방 목소리가 녹음되지 않습니다

의도된 동작입니다. Minit은 **마이크 입력만** 녹음합니다. 컴퓨터에서 재생되는 소리는 잡지
않습니다. 마주 앉아서 하는 회의를 위한 앱입니다.

## Slack으로 발송되지 않습니다

발송할 채널에 **봇을 초대했는지** 확인하세요. 초대한 채널만 설정 화면 드롭다운에 나타납니다.

`채널명 → 통합 → 앱 → Minit 추가`로 초대한 뒤 설정에서 채널을 다시 선택합니다.
발송이 실패해도 회의록 저장에는 영향이 없습니다. → [Slack 자동 발송](../slack/)

## 회의록이 GitHub에 올라가지 않습니다

회의록은 항상 먼저 로컬에 저장되므로 **유실되지 않습니다.** 업로드가 실패하면 다음 회의
저장 시점이나 앱에 다시 포커스할 때 자동으로 재시도합니다. → [GitHub 백업](../github-backup/)

## 실수로 회의록을 지웠습니다

지운 파일은 **휴지통으로 이동**합니다. 휴지통에서 되돌릴 수 있습니다.

## 녹음 도중 앱이 꺼졌습니다

다음 실행 시 완료되지 못한 녹음이 있으면 앱이 알려주고, 이어서 처리할지 물어봅니다.

## 해결되지 않으면

[GitHub 이슈](https://github.com/git-artinus/minit/issues/new/choose)로 알려주세요.
**Minit 버전**(설정 하단에서 확인)과 **Mac 종류**를 함께 적어주시면 빠르게 확인할 수 있습니다.
